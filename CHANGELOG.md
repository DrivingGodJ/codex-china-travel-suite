# Changelog

## 0.2.0 - 2026-10-18

- Added an iCloud Calendar skill for duplicate checks, existing-calendar classification, reminders, and verified event moves.
- Documented the independently configured CalDAV connection, app-specific credentials, and Windows environment refresh.
- Added a rail-trip planning skill for exact stations, appointment buffers, last connections, login recovery, and authorized booking assistance.
- Distinguished suggested journeys, pending-payment orders, and paid tickets; documented official-App payment handoff when a browser blocks the flow.
- Connected the new workflows to AMap planning without bundling third-party rail clients, another calendar server, or private trip data.

## 0.1.0 - 2026-08-24

- Initial public release.
- Bundled AMap, DiDi, Fliggy, and Meituan Travel skills.
- Added MCP bridges with external credential loading and redacted diagnostics.
- Added explicit confirmation boundaries for ride ordering and cancellation.
